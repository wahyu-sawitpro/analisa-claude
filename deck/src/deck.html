Buka di Google Slides

Deck disimpan sebagai file PowerPoint, lalu diimpor ke Google Slides. Semua teks, tabel, dan grafik tetap bisa diedit.

  1. Klik Unduh PPTX di bawah dan simpan filenya.
  2. Buka Google Drive, klik Baru → Upload file, lalu pilih file .pptx tadi.
  3. Klik kanan file tersebut → Buka dengan → Google Slide.

Untuk menambahkan ke presentasi yang sudah ada: buka presentasinya di Google Slides → File → Impor slide.
